# AutoSDD 文档

AutoSDD 是一个最小可运行的 SDLC 系统：把 Agent、Workflow 与任务执行串成可观察的闭环。文档按用途分为四类：

| 文档 | 适合谁 | 内容 |
|---|---|---|
| [使用指南](guide/README.md) | 使用者 / 演示者 | 安装配置、页面操作、完整演示、常见问题，含全流程截图 |
| [设计文档](design/README.md) | 开发者 / 评审者 | 架构、领域模型、执行引擎、API、前端、安全、测试、路线 |
| [功能清单](FEATURES.md) | 产品 / 项目跟踪 | 已实现与待实现功能，逐项映射到设计文档与代码入口 |
| [远程沙箱设计](design/11-sandbox.md) | 架构评审 | 远程 Bubblewrap 沙箱与沙箱管理的设计草案（未实现） |

## 快速入口

- 想先把系统跑起来：看 [使用指南 · 快速开始](guide/README.md#1-快速开始)
- 想知道某个功能是否已有：看 [功能清单](FEATURES.md)
- 想理解一次任务如何执行：看 [执行引擎](design/04-execution.md) 与 [上下文管理](design/10-context.md)
- 想评审远程沙箱方案：看 [远程沙箱设计](design/11-sandbox.md)

## 文档维护

- 功能变化时，同步更新设计文档、[功能清单](FEATURES.md) 与使用指南；
- 未实现的设计单独成篇并在开头标注「草案」，不混入已实现文档；
- 使用指南截图由 `e2e/scripts/screenshots.mjs` 生成，UI 调整后重新运行；
- 文档中的代码路径、测试数量、截图均应与仓库当前状态一致。
