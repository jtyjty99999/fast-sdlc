## 一句话架构

```
React SPA ──REST/SSE──► Fastify + SQLite
                          ├─ Domain：Agent / Skill / Knowledge / Model / Workflow / Task
                          ├─ Execution：上下文组装 → Executor（Mock/Anthropic/OpenAI）→ 编排器
                          └─ Overview：聚合指标
```

任务启动时冻结工作流与 Agent 画像，按 `depends_on` 计算就绪步骤，逐步调用模型；状态与事件写入 SQLite，并通过 SSE 实时推送到浏览器。步骤之间只共享最终 Markdown 产物，不共享对话历史。

## 文档约定

1. **实现优先**：`01`–`10` 描述代码当前真实行为；如果实现与文档不一致，以代码为准并尽快修文档。
2. **草案隔离**：未实现的设计放在 `11-sandbox.md`，开头标注「设计草案，不包含实现」，不与已实现文档混写。
3. **同源引用**：设计文档引用代码路径与测试文件；功能变化时同步更新 [功能清单](../FEATURES.md) 与 [使用指南](../guide/README.md)。
4. **截图可重建**：使用指南中的图片由 `e2e/scripts/screenshots.mjs` 生成，UI 改动后重新运行脚本。
5. **安全边界**：默认本地单用户、无鉴权；任何「公网可用」「多租户」的描述都必须同时给出鉴权与隔离方案，不能默认成立。
